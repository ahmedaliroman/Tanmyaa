# Tanmyaa — OpenAI-powered consulting website

All AI generation is handled server-side through OpenAI. The API key is never exposed to the browser.

## Run locally

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` or `.env.local`.
3. Set `OPENAI_API_KEY` and the required Supabase/PayPal variables.
4. Start the app: `npm run dev`
